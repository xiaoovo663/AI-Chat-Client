# AI Chat Client

> 一个单文件、零后端、开箱即用的纯前端 AI 对话客户端。

[在线体验](https://ai-ol.pages.dev) · [开源仓库](https://github.com/xiaoovo663/AI-Chat-Client) · [MIT License](https://github.com/xiaoovo663/AI-Chat-Client/blob/main/LICENSE)

---

## 📌 项目简介

AI Chat Client 是一个面向个人用户的轻量级 AI 对话客户端。核心目标：

- **无需安装**：不需要 Node.js、npm、构建工具或后端服务；
- **无需部署后端**：浏览器直接请求你配置的 OpenAI 兼容接口；
- **双击即用**：下载 `index.html` 后用浏览器打开即可对话；
- **数据本地化**：API 配置与聊天记录保存在浏览器 `localStorage`；
- **广泛兼容**：支持所有遵循 OpenAI API 规范的服务，包括云端 API 与本地模型。

项目采用 MIT License 开源，可自由使用、修改与分发。

> **同步状态**  
> 在线体验版与开源仓库已完成功能同步。当前仓库包含多会话管理、对话导出、深色主题、Markdown 渲染增强、PWA / 离线启动、多 LLM Profile、上下文裁剪等增强能力。  
> 若后续在线版短暂领先于仓库，会在 README 与 Release 中明确标注。

## ✨ 项目特性

### 基础能力

- **单文件分发**：核心仅一个 `index.html`，无需构建，下载后双击即可运行。
- **OpenAI 接口兼容**：支持 OpenAI、DeepSeek、Moonshot、通义千问、One API、New API、本地 Ollama 等。
- **流式输出**：支持 SSE 流式回复，呈现打字机效果。
- **多模态图片上传**：支持图片上传与自动压缩，需搭配视觉模型使用。
- **模型列表获取**：配置 API 后可尝试一键获取模型列表。
- **参数调节**：支持 `temperature`、`top_p` 等常用生成参数。
- **响应式界面**：适配桌面、平板与移动端。
- **本地数据存储**：配置与聊天记录保存在浏览器 `localStorage`。
- **无后端依赖**：不收集、不存储用户对话内容。
- **MIT 开源**：可自由使用、修改与分发。

### 增强能力

- **多会话管理**：支持会话列表、切换与会话维护。
- **对话导出**：支持导出对话内容，便于备份与分享。
- **深色主题**：支持浅色 / 深色主题切换。
- **Markdown 渲染增强**：改善代码块、列表、表格等内容的展示。
- **PWA / 离线启动**：支持安装到桌面 / 主屏幕，并缓存应用外壳。
- **多 LLM Profile**：支持保存多套 API 地址、Key 与参数组合，方便切换服务商。
- **上下文裁剪 / 长对话优化**：对长对话上下文进行裁剪，降低 token 成本与超限风险。

## 🌐 在线体验与本地使用

### 在线体验

直接访问：

**https://ai-ol.pages.dev**

无需安装。打开页面后进入设置，填写 API Base URL、API Key 与模型名称即可开始对话。

> 在线体验版用于演示与快速试用。请勿在公共设备上保存长期使用的 API Key。

### 本地使用

1. 克隆仓库：

   ```bash
   git clone https://github.com/xiaoovo663/AI-Chat-Client.git
   cd AI-Chat-Client
   ```

2. 双击打开 `index.html`，或使用浏览器打开该文件；

3. 在设置中填写：

   - API Base URL
   - API Key
   - 模型名称

4. 保存配置后开始对话。

> 部分服务商存在 CORS 限制，直接本地打开 `index.html` 可能无法请求 API。可部署到静态托管平台、使用支持跨域的服务商，或自建代理。

## ⚙️ 配置说明

| 配置项 | 是否必填 | 说明 | 示例 |
| --- | :---: | --- | --- |
| API Base URL | 是 | OpenAI 兼容接口地址 | `https://api.openai.com/v1` |
| API Key | 通常是 | 服务商密钥；本地 Ollama 可留空或填任意值 | `sk-...` |
| 模型名称 | 是 | 要调用的模型 ID | `gpt-4o-mini`、`deepseek-chat` |
| temperature | 否 | 生成随机性，通常 0–2 | `0.7` |
| top_p | 否 | 核采样参数，通常 0–1 | `1` |

### 常见服务商示例

| 服务商 | API Base URL | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| Ollama 本地 | `http://localhost:11434/v1` | `llama3.1` |
| One API / New API | 你部署的网关地址，通常以 `/v1` 结尾 | 网关中配置的模型 ID |

> 不同服务商对路径、鉴权和参数支持不同，请以服务商文档为准。

## 🧩 功能说明

### 多会话管理

支持创建、切换与维护多个会话。聊天记录保存在浏览器 `localStorage`，清除浏览器数据后会丢失，且不会跨设备同步。

### 对话导出

支持将对话导出为文本或 Markdown（以实际页面为准），便于备份、归档与分享。导出前请确认内容中不包含敏感信息。

### 深色主题

支持浅色 / 深色主题切换，主题偏好保存在本地浏览器。

### Markdown 渲染增强

改善代码块、列表、表格等内容的展示。AI 输出属于不可信内容，渲染时应做好转义与清洗，避免 XSS 风险。

### PWA / 离线启动

支持安装到桌面 / 主屏幕，并通过 Service Worker 缓存应用外壳。离线状态下可启动应用外壳，但 API 请求仍需网络。

### 多 LLM Profile

支持保存多套 API 地址、Key 与参数组合，方便在 OpenAI、DeepSeek、Ollama、One API 等服务商之间切换。

### 上下文裁剪 / 长对话优化

长对话时对上下文进行裁剪，降低 token 成本与超限风险。具体裁剪策略以实际实现为准，重要对话建议及时导出备份。

### 图片上传

图片上传需要：

1. 选择支持视觉能力的模型；
2. 服务商接口支持图片输入；
3. 图片经过自动压缩后仍满足模型要求。

> 图片会上传到你所配置的 API 服务商，不会上传到本项目服务器。请勿上传敏感图片。

## 📦 部署指南

本项目可部署在任意静态托管平台。

### Cloudflare Pages

1. 登录 Cloudflare Pages；
2. 连接 GitHub 仓库，或直接上传静态文件；
3. 构建命令留空；
4. 输出目录填写项目根目录；
5. 部署完成后访问分配的域名。

### GitHub Pages

1. 将项目推到仓库；
2. 进入 Settings → Pages；
3. 选择分支与根目录；
4. 保存并等待部署。

### Vercel / Netlify

- Framework Preset 选择 Other；
- Build Command 留空；
- Output Directory 填写项目根目录；
- 部署。

### 静态文件服务器

将 `index.html` 及 PWA 相关静态资源上传到任意静态服务器即可。建议使用 HTTPS，部分浏览器能力在非安全上下文中可能受限。

## ❓ FAQ

### Q1：在线版和开源仓库功能一致吗？

当前已完成同步，功能基本一致。若后续在线版短暂领先，会在 README 与 Release 中标注。

### Q2：本地打开 `index.html` 无法请求 API？

部分服务商存在 CORS 限制。可尝试使用支持跨域的服务商、部署到静态托管平台、自建代理，或检查 Base URL 是否包含正确的 `/v1` 路径。

### Q3：聊天记录存在哪里？

保存在当前浏览器的 `localStorage`。清除浏览器数据后会丢失，且不会跨设备同步。

### Q4：API Key 会上传到服务器吗？

不会。本项目无后端，Key 仅保存在本地浏览器中。对话请求由浏览器直接发送到你配置的 API 服务商。

### Q5：如何切换不同服务商？

修改 API Base URL、API Key 与模型名称即可；也可使用多 LLM Profile 保存多套配置。

### Q6：为什么获取模型列表失败？

可能是服务商未开放 `/models` 接口、Key 权限不足、CORS 限制或 Base URL 路径不正确。手动填写模型名称即可。

### Q7：图片上传失败怎么办？

请确认当前模型支持视觉输入、服务商接口支持图片消息、图片大小与格式符合要求、网络与 CORS 正常。

### Q8：在线版和本地版的数据互通吗？

不互通。不同域名下的 `localStorage` 相互隔离，配置与聊天记录不会自动同步。

### Q9：可以商用吗？

项目基于 MIT License，可自由使用、修改与分发。使用第三方 API 时请遵守对应服务商的条款与计费规则。

### Q10：如何清除本地数据？

可在浏览器设置中清除该站点的存储数据，或在页面设置中删除配置与聊天记录。
